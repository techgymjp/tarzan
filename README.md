# ターザン大東京（TARZAN DAI-TOKYO）

実在の東京都心を 3D で再現した街を、ロープ1本でビルからビルへ飛び移っていくブラウザ 3D アクションです（three.js）。
ビルの形と高さは **国土交通省 PLATEAU** の 3D 都市モデル、首都高の高架は **OpenStreetMap** の線を使っていて、
新宿・渋谷・六本木・霞が関・永田町・赤坂・銀座・汐留・東京駅・大手町・水道橋・飯田橋、お茶の水・秋葉原・上野・浅草など、都心と下町の約6.3万棟が実際の輪郭と高さで建っています。皇居のお濠や庭園の池・川・運河も、国土地理院のデータから実際の形で描いています。

# → http://localhost:8000/

## 最新の遊び方（ヘリと鬼ごっこ）

- **日本語 / English**: ブラウザの言語で自動で切り替わる。タイトル画面の「言語 / Language」でも変えられる（画面の文字・ステージ名・地名・著名なビルと名所の名前・共有文。PLATEAU の一般のビル名とミニマップの地図の文字は日本語のまま）。文字は `js/i18n.js`

- **ステージの鍵**: 首都高グランプリと同じく、最初は「霞が関デビュー」だけ。クリアすると次のステージの鍵が開く（結果画面に「次のステージへ」）。フリー（ビル図鑑あつめ）は全ステージクリアで開く。テスト用に `index.html?unlock` で全部開く

- **ロープはヘリから**: すぐ前を飛ぶヘリコプターがターザンロープを垂らしている。「つかめる！」と出たらスペース（スマホは「つかむ」ボタン、左クリックでも可）でつかまり、もう一度で離す。ジャンプは Shift。つかまっている間はヘリが前へ運んでくれる。空中でもぶら下がり中でも左右（A D・スティック）で曲がれる（ヘリも曲がる）。移動は押し続けるほど加速
- **鬼ごっこ**: 雲に乗った鬼が街を徘徊していて、280m 以内に近づくと見つかって追いかけてくる（420m 離れると見失う。時間がたつほど速くなる）。**捕まったらアウト、ゲーム終了**。鬼の数はステージに応じて決まる: 霞が関デビュー（10匹、1kmあたり約5.4匹）を基準に、ステージが上がるごとに 15% ずつ過密になる（六本木 22匹・汐留 27匹・新宿 32匹・東京ドーム→武道館 約45匹・C1 100匹）。チェックポイントを1つ取るごとに1匹増える。フリーは霞が関デビューと同じ過密度（ビルのある所 1km² あたり約12匹）を、プレイヤーのまわり半径1.2km で保つ。追われている間は警報と心臓の音、画面のふちが赤くなる（清水の舞台から飛び降りるつもり の鬼を元にしている）
- **花火**: 屋上の光の玉（チェックポイント）にちゃんと触れて通過したときだけ花火が上がる。ロープでほかのビルの屋上に着地できたら +500pt
- **ジャンプ**: 約15m の高さまで跳べる
- **ビル図鑑**: 名前のあるビル（著名なビル34棟に実際の名前を付け、PLATEAU の名前と合わせて約125棟）の屋上に降りると登録。著名なビルには街の上にラベルが浮かぶ
- **一番近い鬼までの距離**: 左下に表示（清水の舞台から飛び降りるつもり と同じ）。近いとオレンジ、追われていると赤く点滅
- **ミニマップ**: 国土地理院の淡色地図（ズーム16の詳しい地図をまわりだけ読み込む。半径約250m、速いときは広く）。進行方向が上。自分は青い矢印、次のチェックポイントは赤い✦、鬼は赤丸の👹（追ってくる鬼は点滅）。地図の外にある次のチェックポイントと追ってくる鬼は、ふちに矢印つきで出る。ミニマップをタップ（N キー）で大きく広げる
- **シェア**: 結果画面の「シェアする」で、スマホは端末の共有メニュー、パソコンは X の投稿画面を開く（「結果をコピー」で文章をコピー）。共有文には紹介記事の URL（https://techgym.jp/column/claude-code-game-tarzan/ 。`js/main.js` の `SHARE_URL`）が付く
- **BGM**（B キーかタイトルで ON/OFF）とヘリの音。カメラはいつもプレイヤーの後ろから
- **東京ドーム**: PLATEAU では円柱の箱なので、白い膜屋根がふくらんだドーム（直径約200m・高さ約56m）に作り直した。屋根の上に降りられ、図鑑にも載る。夜はナイターで屋根がほんのり光る
- **日本武道館**: PLATEAU では八角形の箱なので、反りのある八角形の大屋根と上の段、金色の擬宝珠（ぎぼし）を手作り（幅約110m・高さ約46m）。屋根の段に降りられ、図鑑に載る。C1 ぐるり大冒険のチェックポイント（旧「九段」）は武道館の大屋根の上
- **永田町・霞が関・皇居まわり**: 首都高がトンネルで帯から外れる所の建物（首相官邸・国立国会図書館・最高裁判所・自由民主党本部・警視庁本部など約2,600棟）を PLATEAU のベクトルタイルで補った。お濠（千鳥ヶ淵・半蔵濠・桜田濠など）・小石川後楽園の池・川・運河は国土地理院のベクトルタイルの水面。桜田門（渡櫓門と高麗門）・半蔵門・皇居前広場（砂利道と黒松の芝生）は手作り
- **お茶の水・秋葉原・上野・浅草**: 建物は PLATEAU のベクトルタイルで補う（高さ15m未満の小さな建物は省く）。不忍池・神田川・隅田川は国土地理院の水面。手作り: 浅草寺（本堂・五重塔・宝蔵門・雷門と大提灯）、アサヒ スーパードライホールの金の炎とビアタワーの泡、西郷隆盛像、不忍池の弁天堂、ニコライ堂、神田明神、聖橋、将門塚、東京駅 丸の内駅舎、総武線の高架と黄色い電車、万世橋のレンガ高架と中央線のオレンジの電車、秋葉原 電気街の看板（架空の店）
- **赤坂**: 豊川稲荷・日枝神社（山王鳥居）・ホテルニューオータニ本館（屋上の青いラウンジ）を手作り。赤坂見附の西側の建物も PLATEAU で補う
- **皇居**: データの範囲外で緑地だったので手作り。宮殿（長和殿・正殿・豊明殿などの緑の銅板屋根の殿舎）、伏見櫓・富士見櫓・桜田巽櫓、二重橋とお濠、東御苑の江戸城天守台。屋根に降りられ、図鑑に載る
- **東宮御所**（赤坂御用地）: 白い壁と緑青の銅板屋根の御所を手作り
- **テックジム東京本校**（千代田区平河町2-7-2 VORT永田町 6F）: 首都高グランプリのモデルを元に、10階建てのビル・6階のオレンジの帯「TECH GYM 6F」・屋上の紅白の鉄塔と看板、高さ約520m・直径約140mの **アドバルーン**（縦書きの垂れ幕つき。風でゆっくり揺れ、霧で消えないので遠くからも見える）。屋上に降りると図鑑に載る

## ゲームのしくみ

### ロープアクション
- 照準が **緑** になったら、そこにロープが届く（最大150m）。照準の真ん中に壁がなくても、近くの壁を自動で探す（スマホは広め）
- ロープは張っているときだけ効く「伸びない振り子」。重力は本物の約3倍にしてあり、ビルの大きさで振り子が気持ちよく回る
- ぶら下がりながら **W で前にこぐ** と振り子が大きくなる。**Shift で巻き取る** と上に登れる
- **ぐいっ**（Space）でアンカーに向かって一気に引き寄せる（0.9秒ごと）
- 振り子の **いちばん下を過ぎて上がり始めたところで手を離す** と「ナイスリリース！」で 14% 加速して少し浮く。タイミングが腕の見せどころ
- 振り子の最下点が地面にぶつかりそうなら自動で少し巻き取る（地面すれすれを抜けるアシスト）
- 壁に当たると減速、強く当たると「ゴツン！」。高い所から落ちて強く着地すると少しよろける
- 屋上と首都高の高架の上は走れる・着地できる

### 得点
- **コンボ**: 地面に足を着けずにロープをつなぐたびに +1。得点の倍率が上がる（最大 ×8.5）。
  屋上や高架の上なら1秒までは着地してもコンボが続く。地面に降りると終わる
- 空中にいる間は速さに応じて加点、ナイスリリース +200、壁すれすれを高速で抜ける **ニアミス** +300（いずれもコンボ倍率つき）

### 配達ミッション（タイムアタック）
ビルの屋上に置いた **光の玉（チェックポイント）** を順に取ってゴールを目指す（ヘリで運んでもらって屋上に降りる）。次の玉は大きく脈打って光り、画面上の矢印（▲▼ は上下）とミニマップの赤丸で分かる。

### フリーターザン・ビル図鑑
霞が関ビルの屋上から自由に飛び回るモード。**PLATEAU に名前が入っている建物**（霞が関ビルディング・汐留メディアタワー・日本テレビタワー・渋谷ヒカリエ・大手町タワーなど119棟と、東京タワー・国会議事堂）に
ロープを掛けると「ビル図鑑」に登録される（+1000pt）。ミニマップのピンクの点がまだ登録していない建物。
ロープを掛けた建物の名前と高さが画面に出るので、実在の街を探検する楽しみがある。

### 街の演出
- 今いる地域（霞が関・銀座・六本木・渋谷…）に入ると画面に地名が出る
- 時間帯は「昼」「夕暮れ」「夜」（夜は窓明かりとオレンジに光る東京タワー、星空）
- PLATEAU では箱になってしまう **東京タワー**（トラスと脚の間をくぐれる当たり判定）と **国会議事堂** は手作りのモデル。遠くに東京スカイツリーと富士山
- 首都高の高架（橋脚つき）、屋上の設備、データの範囲外（皇居・神宮外苑・赤坂御用地・住宅地）は緑地と木々（10月なので銀杏の黄色と紅葉）
- 速さに応じて視野が広がり、集中線と風切り音

## 街のデータの作り方

`js/city-data.js` は [首都高グランプリ](https://github.com/techgymjp/shutoko) のコースデータ（`js/course-*-data.js`。首都高に沿った PLATEAU の建物と OSM の首都高の線）から作ります。

```sh
git clone --depth 1 https://github.com/techgymjp/shutoko ../shutoko
python3 tools/build_city.py ../shutoko/js > js/city-data.js
```

- 全コースの建物を緯度経度に戻し、都心の範囲（北緯35.645〜35.712、東経139.690〜139.785）にあるものを、原点を国会議事堂のあたりにした1つの座標系（x: 東、z: 南、m）にまとめる
- 複数のコースに入っている同じ建物は、重心と高さで見分けて1つにする
- 手作りのモデルに置き換える建物（東京ドーム・日本武道館）は除く
- 街の中で首都高の帯から外れて抜けていた所（虎ノ門〜東京タワー・西新宿・青山など）は、高さ25m以上の建物を `data/plateau-tall.json` で補う
- コースデータにない所（永田町・霞が関・皇居まわり）は `tools/fetch_plateau_mvt.py` で PLATEAU のベクトルタイルから取り出した `data/plateau-extra.json` で補う（`python3 tools/build_city.py ../shutoko/js data/plateau-extra.json > js/city-data.js`）
- 水面は `python3 tools/fetch_water.py > js/water-data.js`（国土地理院 ベクトルタイルの waterarea）
- 首都高の線も重なりを除いて1本にする（トンネル区間は印を付けて描かない）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `css/style.css` | 画面（タイトル・HUD・スマホの操作ボタン） |
| `js/main.js` | 進行・入力・カメラ・照準（自動照準）・ミッション・得点・図鑑・ミニマップ・空と時間帯 |
| `js/player.js` | プレイヤーの物理（振り子のロープ・走る・跳ぶ・壁と床の当たり判定）とキャラクター・マフラー・ロープの見た目 |
| `js/city.js` | ビルの描画（タイルごとにまとめたメッシュ・窓のテクスチャ・屋上の設備）、首都高の高架、当たり判定、ロープを掛ける所を探すレイキャスト |

| `js/missions.js` | 配達ミッションのルートと地域名 |
| `js/i18n.js` | 日本語 / 英語の文字（画面・地名・ビル名） |
| `js/audio.js` | 効果音（すべて WebAudio で合成） |
| `js/city-data.js` | 街のデータ（自動生成） |
| `tools/build_city.py` | 街のデータを作るスクリプト |
